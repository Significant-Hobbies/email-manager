# Design

## Direction

Preserve Kinetic’s quiet, privacy-forward workspace language: dark surfaces by default, an indigo-lifted accent (#8ca4ff), self-hosted Outfit typography for body and headlines, soft borders, and a faint technical grid with an indigo/violet mesh glow.

## Rules

- Public reading surfaces use the existing Astro landing tokens and shell.
- Keep text measures readable and release history chronological.
- Use pills only for compact metadata and actions.
- Dark is the default everywhere, independent of OS preference; no light toggle is needed.
- Use Outfit at 600–700 for display headings; do not use serif headlines.
- Navigation and project-resource links remain keyboard reachable and usable on narrow screens.
